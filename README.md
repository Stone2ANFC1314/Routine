# Ripple

把每天重复的游戏日常自动化掉，点一次就开始，跑完就不用管。

一个 Windows 桌面小工具：把若干现成的游戏自动化工具排成一条队列，按顺序启动、
等它们各自跑完、再处理下一个。

**不需要装 Python。** 去 [Releases](../../releases) 下载 zip，解压双击 `Ripple.exe` 就能用。

---

## 支持的自动化工具

| 游戏 | 工具 | 启动参数 |
|---|---|---|
| 原神 | [BetterGI](https://github.com/babalae/better-genshin-impact) | `startOneDragon` |
| 终末地 | [MaaEnd](https://github.com/MaaXYZ/MaaEnd) | 无 |
| 绝区零 | [绝区零一条龙](https://github.com/OneDragon-Anything/ZenlessZoneZero-OneDragon) | `-o -c` |
| 崩坏：星穹铁道 | [三月七小助手](https://github.com/moesnow/March7thAssistant) | `main --after-finish Exit` |
| 明日方舟 | [MAA](https://github.com/MaaAssistantArknights/MaaAssistantArknights) | 无 |

**这些工具都不随本仓库分发，需要你自己安装。**

---

## 它能做什么

- **排队执行**：拖拽排序，点一次「开始执行」跑完整条队列
- **等待真实结束**：盯进程 / 盯日志判断任务真的完了，不是睡固定秒数
- **超时可调**：每个任务单独设，填 0 表示不限时
- **结束后操作**：关游戏、关工具、退模拟器、锁屏、睡眠、休眠、关机
- **今日状态**：从米游社 / 森空岛读体力与日常进度

## 它不做什么

- **不代替你配置各游戏工具**。打哪个副本、体力怎么花，都在各自工具里设。
  这里只管「什么时候启动、什么时候算结束」。
- **不修改游戏**，不注入、不读内存。全靠调用现成的开源工具。

## 使用方法

### 1. 解压

下载 zip 解压，得到：

```
Ripple\
├── Ripple.exe        双击这个
├── config.json       首次启动自动生成
└── _internal\        程序依赖，不要删
```

**整个文件夹要一起拷走，单独拿 exe 跑不起来。**

### 2. 以管理员身份运行

右键 `Ripple.exe` → 「以管理员身份运行」。

没有管理员权限的话，BetterGI 这类工具没法模拟键鼠，会失败。

### 3. 配置各工具的路径

首次启动会填入一份默认清单，**里面的路径是按常见安装位置猜的，你需要改成自己机器上的实际路径**。

点每个任务右侧的「设置」，或者点「浏览…」选文件。

填错了那一行会提示「脚本不存在」。

### 4. 调整顺序

按住左边的把手拖动。

**顺序会影响结果**：用 pyautogui 操作前台键鼠的工具不能同时跑，会抢输入。
所以「启动后不等待」的任务（比如 MAA）要放最后。

### 5. 选「结束后操作」

底栏的「结束后：xxx」按钮，点开是多选面板：

- 退出模拟器
- 关闭本次启动的工具
- 锁屏 / 睡眠 / 休眠 / 关机

**这些是整个队列跑完之后才执行的**，不是单个任务结束时。

关机有延迟（默认 60 秒），期间可以取消；人不在的话到点会关。

## 每个任务能设什么

| 设置项 | 说明 |
|---|---|
| 程序路径 | 要启动的 exe |
| 启动参数 | 拼在路径后面，比如 `startOneDragon` |
| 等待方式 | 什么时候算这个任务跑完 |
| 最大运行时间 | 超时后的处理。**填 0 表示不限时** |
| 到时间后 | 强制结束并继续 / 不结束跳过 / 停止全部 |
| 后台并行 | 启动后队列继续，不等它结束 |

**等待方式怎么选**：

- `等待直接启动进程`（默认）——等进程退出。适合跑完会自己关的
- `启动后不等待`——启动后不管。适合 MAA 这种自己会结束的
- 另外两种按窗口标题 / 命令行关键词判断

## 关于超时和卡住

总运行时间是兜底，不是判断任务是否卡住的手段。

同一台机器、同一个工具，实际耗时可能从 40 秒到 4 小时 51 分——
取决于当天开了哪些功能。所以默认给了宽松的上限，
真需要时可以填 0 完全不限制。

## 已知问题

- 森空岛接口偶尔不稳定，状态可能显示「请求异常」，刷新一下通常就好
- MAA 设成「启动后不等待」后不受超时保护，卡住需要人工处理
- 星铁的三月七小助手需要 `--after-finish Exit` 才会关游戏，默认清单里已经带上了
