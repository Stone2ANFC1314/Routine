# Ripple

把每天重复的游戏日常自动化掉，点一次就开始，跑完就不用管。

一个 Windows 桌面小工具：把若干现成的游戏自动化工具排成一条队列，按顺序启动、
等它们各自跑完、再处理下一个。

**不需要装 Python。** 去 [Releases](../../releases) 下载 zip，解压双击 `Ripple.exe` 就能用。

---

## 支持的自动化工具

| 游戏 | 工具 | 启动参数 |
|---|---|---|
| 原神 | [BetterGI](https://github.com/babalae/better-genshin-impact) | `startOneDragon` |
| 终末地 | [MaaEnd](https://github.com/MaaXYZ/MaaEnd) | 无 |
| 绝区零 | [绝区零一条龙](https://github.com/OneDragon-Anything/ZenlessZoneZero-OneDragon) | `-o -c` |
| 崩坏：星穹铁道 | [三月七小助手](https://github.com/moesnow/March7thAssistant) | `main --after-finish Exit` |
| 明日方舟 | [MAA](https://github.com/MaaAssistantArknights/MaaAssistantArknights) | 无 |

**这些工具都不随本仓库分发，需要你自己安装。**

> 表格里是默认清单的常见搭配。填别的程序也能用——它本质上就是个排队启动器。

---

## 它能做什么

- **排队执行**：拖拽排序，点一次「开始执行」跑完整条队列
- **等待真实结束**：盯进程 / 盯窗口 / 盯命令行，判断任务真的完了，不是睡固定秒数
- **超时可调**：每个任务单独设，填 0 表示不限时
- **结束后关机**：整条队列跑完后可以自动关机，有延迟可取消
- **今日状态**：从米游社 / 森空岛读体力与日常进度
- **美图画廊**：把喜欢的图丢进一个目录，按原比例平铺展示

## 它不做什么

- **不代替你配置各游戏工具**。打哪个副本、体力怎么花，都在各自工具里设。
  这里只管「什么时候启动、什么时候算结束」。
- **不修改游戏**，不注入、不读内存。全靠调用现成的开源工具。

## 使用方法

### 1. 解压

下载 zip 解压，得到：

```
Ripple\
├── Ripple.exe        双击这个
├── config.json       首次启动自动生成
└── _internal\        程序依赖，不要删
```

**整个文件夹要一起拷走，单独拿 exe 跑不起来。**

### 2. 以管理员身份运行

右键 `Ripple.exe` → 「以管理员身份运行」。

没有管理员权限的话，BetterGI 这类工具没法模拟键鼠，会失败。

### 3. 配置各工具的路径

首次启动会填入一份默认清单，**里面的路径是按常见安装位置猜的，你需要改成自己机器上的实际路径**。

点每个任务右侧的「设置」，或者点「浏览…」选文件。

填错了那一行会提示「脚本不存在」。

### 4. 调整顺序

按住左边的把手拖动。

**顺序会影响结果**：用前台键鼠的工具不能同时跑，会抢输入。
所以「启动后不等待」的任务（比如 MAA）要放最后。

### 5. 选择跑完之后做什么

底栏有一个「结束后关机」的开关。

各工具跑完一般都会自己关游戏、自己退出，所以这里只保留了关机这一项。
关机有延迟（默认 60 秒），期间可以取消；人不在的话到点会关。

## 每个任务能设什么

| 设置项 | 说明 |
|---|---|
| 程序路径 | 要启动的 exe |
| 启动参数 | 拼在路径后面，比如 `startOneDragon` |
| 等待方式 | 什么时候算这个任务跑完 |
| 最大运行时间 | 超时后的处理。**填 0 表示不限时** |
| 到时间后 | 强制结束并继续 / 不结束跳过 / 停止全部 |
| 后台并行 | 启动后队列继续，不等它结束 |

**等待方式怎么选**：

| 选项 | 什么时候用 |
|---|---|
| 等待直接启动进程 | 默认。等进程退出，适合跑完会自己关的 |
| 等待指定进程名 | 启动器只是拉一下，真正的活在另一个进程里 |
| 启动后不等待 | 启动后不管，适合 MAA 这种自己会结束的 |
| 等待窗口标题出现后消失 | 用窗口判断起止 |
| 等待命令行出现后消失 | 用命令行参数判断起止 |

## 主题

这个版本**不带任何美术素材**，开箱是「简约」主题。

标题栏右侧的主题按钮可以切换，但另外几个主题（昔涟、星空夜、浅汐）
需要你自己准备背景图才能完整显示。没有素材时会自动退回简约，
**功能完全不受影响**。

素材怎么放、图片规格要求，见 `tools/prepare_assets.py` 开头的说明。

---

## 关于「今日状态」这一栏

左栏会显示各游戏的体力和日常进度，数据来自米游社和森空岛。
**这需要登录，而目前没有做界面入口。**

也就是说：新装的话这一栏会显示「尚未登录」，队列功能不受影响。

要用的话需要自己放凭据文件，位置在程序旁的 `.ripple\` 目录：

| 文件 | 内容 |
|---|---|
| `mihoyo_cookies.bin` | 米游社 Cookie（原神 / 绝区零 / 星铁） |
| `skland_full.json` | 森空岛 cred + token（终末地 / 明日方舟） |

这部分还没做成一键登录，属于**未完成的功能**。

### 升级不会丢账号

凭据放在 `.ripple\` 里。程序启动时会从 exe 所在目录**逐级往上找**这个目录，
所以覆盖安装、换一个版本的文件夹，账号都还在，不用重新登录。

如果同时装了多个账号，可以在 `config.json` 里指定每个游戏读哪个：

```json
{
  "mihoyo_account_prefer": {
    "genshin": "米游社ID",
    "zzz": "米游社ID",
    "starrail": "米游社ID"
  },
  "mihoyo_role_uid": {
    "starrail": "角色UID"
  }
}
```

不填就按「第一个匹配到的角色」走，单账号用户不用管这一段。

## 关于超时和卡住

总运行时间是兜底，不是判断任务是否卡住的手段。

同一台机器、同一个工具，实际耗时可能差很多——取决于当天开了哪些功能。
所以默认给了宽松的上限，真需要时可以填 0 完全不限制。

## 已知问题

- 森空岛接口偶尔不稳定，状态可能显示「请求异常」，刷新一下通常就好
- MAA 设成「启动后不等待」后不受超时保护，卡住需要人工处理
- 星铁的三月七小助手需要 `--after-finish Exit` 才会关游戏，默认清单里已经带上了
- 游戏自动化工具本身偶尔会卡在读条界面，这种情况靠超时兜底，不会卡死队列

## 从源码运行

```cmd
pip install -r requirements.txt
python Anigame-script-manager\main.py
```

打包：

```cmd
pyinstaller build_exe.spec --noconfirm
```

设环境变量 `RIPPLE_LITE=1` 再打包，可以生成不带素材的素版。
